# Angulus V1.4.04

以 V1.4.03 為基礎新增「裝備訂製管理」獨立 Google 試算表管理系統。

- 套裝大類、名稱、方式、固定價或待報價、說明、排序與上下架由試算表控制。
- 方案編號在編輯試算表時自動生成。
- Google Apps Script 後端依有效的上架資料核價，不信任前端顯示價；保留舊訂單快照。
- 前台動態渲染裝備名稱與訂製方式，保留職業圖示及「其他」自由委託。
- 既有一般商品管理、Google 接單與通知程式保留。

**正式部署順序：** Apps Script 程式 → 執行一次 `upgradeAngulusEquipmentCatalog` → 更新 `/exec` 部署 → GitHub 網站四檔。詳細步驟見《部署與維護教學.md》。

目前尚未連到你的實際 Apps Script 專案執行安裝；發行 ZIP 不等於正式環境已更新。
