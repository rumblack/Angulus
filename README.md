# Angulus — GitHub Pages V1.3.2

本版從 V1.3.1 更新：
- 全站店名統一為 **Angulus**。
- 刪除首頁右側「ABOUT THE ATELIER」介紹框。
- 首頁 Hero 改為單欄精簡版，縮減標題及上下留白。
- 保留純文字商品卡、Gil 計價、數量按鈕、客製委託、表單與 Formspree 設定方式。

## 更新 GitHub Pages
將 `index.html`、`styles.css`、`script.js`、`config.js` 覆蓋上傳到原本 repository 根目錄。`README.md` 可一併上傳。

## 設定商品及訂單
在 `config.js` 中修改 `products` 及 `formEndpoint`。**GitHub Pages 為靜態網站，不會自行儲存訂單**；表單須連結至 Formspree 等服務，並自行測試正式送單。

## V1.3.11 — 獨立分類與內嵌客製委託
- 商品分頁固定為「常駐商品」、「少量購買」、「客製化委託」；不再有「全部」。
- `config.js` 商品 `category` 設為 `常駐商品` 或 `少量購買`，即可指定商品顯示在哪個分頁；舊資料未使用這兩類的固定價格商品預設歸到常駐商品。
- 預設範例：華麗書房椅、書架組合在「常駐商品」，寶石燈飾在「少量購買」。
- 客製委託分頁改成內嵌表單，填寫需求後加入右側訂購申請單，待店主報價。
- 若已有客製的商品（`price:null`），其申請方式統一使用客製委託分頁，不另外顯示商品卡。
- GitHub Pages 仍是靜態網站，真正送單需在 `config.js` 設定 `formEndpoint`。
