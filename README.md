# Angulus V1.4.05

以 V1.4.04 為基礎的裝備同步容錯、顯示文字與客人提示修正版。

- 裝備訂製清單採逐筆檢查，格式錯誤、重複方案及無效固定售價僅隱藏該方案；一般商品繼續販售。
- 無 `equipment` 清單時，裝備只保留「其他」自由委託；不會將舊固定價資料當作有效價格。
- 裝備新增名稱（例如「新套裝（780/7.5）」）顯示成「新套裝」／「品級 780・7.5」；原始完整名稱用於核價與訂單資料。
- 新加入固定價套裝的提示不再出現雙重括號；待報價方案的說明不再被附在項目名稱上。
- Code.gs 委託查詢與其他顧客可見訊息改為店主口吻。
- 既有訂單不會因此回溯修改；已存入試算表的舊項目名稱仍保持歷史紀錄。

## 部署

詳閱《部署與維護教學.md》：更新 `Code.gs` 後發布新的 Apps Script 網頁應用程式版本，再將 `script.js`、`index.html`、`orders.html` 上傳 GitHub Pages。
不必執行任何初始化函式，不須改動試算表或額外改 `config.js`。
