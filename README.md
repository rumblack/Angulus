# Angulus V1.3.54｜專案總覽

> 本整理版**不升版、不更動功能程式**。僅合併文件、更新過期的說明；網站發布版本仍為 **V1.3.54**。

## 目前的運作方式

- **前台**：GitHub Pages 靜態網站（`index.html`、`styles.css`、`script.js`、`config.js`）。
- **商品**：常駐商品 6 項、少量購買 6 項，另外有「裝備訂製」及「客製化委託」頁籤。價金以 **FF14 Gil** 顯示。
- **裝備訂製**：先選戰鬥裝備或製作採集，再選正式職業（33 張已配置 Icon），選裝備名稱、整套／散件、數量及需求。圖示保存在 `assets/jobs/`；基礎職業未放入。
- **固定價格裝備**：**戰鬥裝備 → 典禮套裝（740）→ 整套**，每套 **500,000 Gil**。其他裝備訂製、散件與一般客製委託仍需報價。
- **接單**：Google Apps Script 為主要接單端，將訂單與明細寫入私人 Google 試算表；Formspree 設定保留為**手動切換**的備援，不會自動雙寫。
- **查單**：`orders.html` / `order-lookup.js`，需角色名稱與每筆訂單的 **40 碼查詢密鑰**；查詢等待上限 30 秒，支援失敗後重試。
- **店主管理**：目前直接在私人 Google 試算表處理訂單、報價、付款及交付狀態，尚無另外的網站管理後台。

## 店舖設定

- 店舖：Angulus；店舖所在 World：伊弗利特；店主：亞德里恩；地址：薰衣草苗圃 11 區 48 號。

## 注意事項

- 最新程式碼已打包並做離線語法／檔案檢查，但**沒有存取你的私人 Google 試算表，也沒有對公開正式網站做端到端驗收**。
- 正式啟用 500,000 Gil 固定售價**必須**讓 `Code.gs` 與 GitHub 前台均部署至本版。詳見 `部署與維護教學.md`。
- 對外公開的接單端點仍存在灌單風險；查詢密鑰要妥善保存，不能代替完整使用者登入。
